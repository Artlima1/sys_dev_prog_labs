05. What are memory leaks, and how can dynamic memory allocation
    contribute to them?

    Memory leaks happen when all references to dynamically allocated memory are lost without properly
    freeing it, leading to its persistence in the system even after program end.
------------------------------------------------------------------------------------
06. What are smart pointers in C++, and why are they used?

    Smart pointers are structures developed in CPP to tie the lifespan of dynamically allocated memory
    to its references and automatically protect from memory leaks.
------------------------------------------------------------------------------------
07. Describe the differences between std::unique_ptr, std::shared_ptr,
    and std::weak_ptr.

    Unique Ptr only allows one unique reference to a allocated structure. When the pointer goes out
    of scope, the pointed memory is also freed

    Shared pointer is a structure that counts number of active references to an allocated memory. The
    memory is automatically freed when there are no more references to it

    Weak pointer are transient pointers that can point to a shared memory but do not increase their
    reference count. Every time they are used, their validity must be checked, for the memory
    they point to might have already been freed.
